# Security Policy

## Supported

Somente a versão atualmente implantada em produção recebe correções.

## Reporting

Não publique vulnerabilidades em issue pública.

Envie o relato para:

`security@SEU-DOMINIO.com`

Inclua:

- endpoint/área afetada;
- passos para reproduzir;
- impacto observado;
- screenshots sem dados pessoais;
- sugestão de correção, se houver.

## Dados reais

Nunca envie em relatório:

- senha;
- service role;
- dados completos de clientes;
- tokens de sessão;
- dumps de banco.

## Resposta

Incidentes críticos devem resultar em:

1. contenção;
2. rotação de credenciais;
3. correção;
4. revisão de logs;
5. análise de impacto;
6. medidas preventivas.
